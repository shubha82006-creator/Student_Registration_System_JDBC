# Student Management System using JDBC

## Project Description
A Java-based Student Management System developed using JDBC and MySQL.

## Features
- Add Student
- View Students
- Update Student
- Delete Student
- Exit

## Technologies Used
- Java
- JDBC
- MySQL
- Maven
- VS Code

## Database
Database Name: studentdb

Table Name: students

## Project Structure
src/main/java/com/student/
- Main.java
- Student.java
- StudentDAO.java
- DBConnection.java

## How to Run
1. Install Java and MySQL.
2. Create the `studentdb` database.
3. Create the `students` table.
4. Update the MySQL username and password in `DBConnection.java`.
5. Run the Maven project.
